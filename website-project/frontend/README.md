# Frontend Drop Folder

Paste the desired frontend code in this folder.

Recommended structure:

```text
frontend/
|-- index.html
|-- about.html
|-- contact.html
|-- assets/
|   |-- css/
|   |-- js/
|   |-- images/
|   `-- fonts/
`-- pages/
```

After the frontend is added, it can be converted into Django templates and connected to the separate website backend.
