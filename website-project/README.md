# Siya Public Website

This folder is reserved for the separate public-facing website.

## Structure

- `frontend/`: Paste the desired HTML, CSS, JavaScript, images, fonts, and other frontend assets here.
- `backend/`: Reserved for the separate Django website backend.
- `docs/`: Website requirements, page map, API contracts, and deployment notes.

The public website remains separate from the existing internal CRM.

Current implementation:

- `frontend/konkit/`: incomplete source template kept as reference.
- `frontend/site/`: reconstructed static design reference.
- `backend/`: working standalone Django + Jazzmin public website CMS.
